# 🚐 TravelTrucks

Сервіс для оренди кемперів TravelTrucks. Тут можна переглянути каталог доступних кемперів, підібрати потрібний за фільтрами та відкрити детальну сторінку з фотогалереєю, характеристиками, відгуками інших користувачів і формою бронювання.

## 📋 Що є в проєкті

Застосунок має 3 сторінки:

- **Головна** (`/`) — банер із коротким описом сервісу та кнопкою переходу до каталогу
- **Каталог** (`/catalog`) — список кемперів із фільтрами (локація, форма кузова, тип двигуна, трансмісія) і довантаженням карток по кнопці "Load More"
- **Деталі кемпера** (`/catalog/[camperId]`) — фотогалерея, повні характеристики транспорту, відгуки з рейтингом та форма для бронювання; відкривається в новій вкладці

## ✨ Функціонал

- 🏠 Перехід з головної сторінки в каталог по кнопці View Now
- 🔍 Фільтрація каталогу за локацією, кузовом, двигуном і трансмісією
- ♾️ Довантаження кемперів по 4 картки через `useInfiniteQuery`
- 🖼️ Галерея фото кемпера з мініатюрами (Swiper)
- ⭐ Відгуки користувачів із п'ятизірковим рейтингом
- 📝 Форма бронювання з валідацією полів і сповіщенням про успішну відправку

## 🛠️ Технології

- **Next.js** (App Router) + **TypeScript**
- **TanStack Query** — `useInfiniteQuery` для пагінації каталогу
- **CSS Modules** — стилі окремо для кожного компонента
- **Swiper** — галерея зображень кемпера
- **Formik + Yup** — форма бронювання та її валідація
- **react-icons** (Phosphor) — іконки інтерфейсу
- **react-hot-toast** — сповіщення

## 🚀 Як запустити локально

Клонувати репозиторій:

```bash
git clone https://github.com/alina-hryhorenko/travel-trucks.git
cd travel-trucks
```

Встановити залежності:

```bash
npm install
```

Запустити в режимі розробки:

```bash
npm run dev
```

Відкрити [http://localhost:3000](http://localhost:3000) у браузері.

## 📦 Продакшн-збірка

```bash
npm run build
npm run start
```

## 📁 Структура проєкту

```
travel-trucks/
├── app/
│   ├── page.tsx                # Головна сторінка
│   ├── catalog/
│   │   ├── page.tsx             # Каталог
│   │   └── [camperId]/
│   │       └── page.tsx         # Деталі кемпера
│   ├── layout.tsx
│   └── icon.png                 # Фавікон
├── components/                   # Кожен компонент — окрема папка з .tsx + .module.css
├── hooks/                         # Кастомні хуки
├── lib/                            # API-запити, кеш, допоміжна логіка
├── types/                          # Типи TypeScript
└── public/
    └── images/                     # Статичні зображення
```
